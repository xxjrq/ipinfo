本站信息以服务商官方页面为准，但官方页面会变化，我们也可能出错。欢迎按本页流程报告问题。

## 如何报告

请到 [xxjrq/ipinfo 的 Issues 页面](https://github.com/xxjrq/ipinfo/issues) 新建 Issue，并按问题类型选择模板：

- **incorrect-information**：内容错误。请写明出错页面的 URL、错误所在段落、正确的信息以及依据（最好是官方页面链接）。
- **broken-link**：链接失效。请写明所在页面与失效链接地址。
- **add-provider**：建议收录服务商。请附上官网、产品页与文档链接，我们会按[收录与核验规则](../how-we-review/)评估。

提交前请确认：反馈内容可公开讨论，不包含你的真实账号、密码或代理凭证。

## 处理流程

1. **受理**：确认 Issue 信息完整，无法确认的会回复补充。
2. **核实**：对照官方页面或相关证据核对。
3. **修正**：修改正文，并同步更新该文的 updatedAt。
4. **回复**：在 Issue 中说明处理结果后关闭。

## 修订记录

本站内容存放在公开 Git 仓库中，每次修改都有提交记录可查。重大修订（如核验规则变化）会在对应页面注明。

## 我们的承诺

- 服务商信息一律以官方页面为准。
- 发现内容过期但尚未复查完成的，先把页面标注为 outdated，而不是继续以旧信息展示。
- 纠错不涉及删除不利结论：核验中发现的问题同样会写入页面。

相关规则见[服务商如何入选与核验](../how-we-review/)与[编辑与事实核验政策](../editorial-policy/)。
