本页说明本站如何决定收录哪些代理 IP 服务商，以及每篇内容上线前经过怎样的核验。规则公开，接受监督。

## 收录条件

服务商满足下列条件中的至少两项，才会进入候选名单：

- 有正常运营的官方网站。
- 官网存在可访问的产品页或定价页。
- 提供正式的产品文档或帮助中心。
- 在目标用户群体中可查证到实际使用量。
- 提供有差异化的代理产品（如特定地区、特定协议或特定计费模式）。
- 支持中文用户常用的付款方式或服务方式。
- 有明确的住宅、静态住宅、移动或数据中心代理产品线。

## 不收录或单独警示的情形

出现以下任一情形的服务商，不予收录；已收录的会标注警示或移入历史记录：

- 官网失效或长期无法访问。
- 无可验证的运营主体。
- 以来源不明的免费代理作为主要宣传。
- 要求下载高风险软件才能使用服务。
- 没有隐私政策和服务条款。
- 冒用其他品牌的名称、商标或素材。
- IP 来源的合规性无法确认。
- 只有二手推广文章，没有任何官方资料可供核对。

## 核验流程

每篇服务商内容上线前按固定顺序执行五步核验：

1. **官网**：确认官网可正常访问，主体信息可查。
2. **定价**：核对产品页与定价页的套餐、价格、计费模式。
3. **文档**：核对官方文档中的认证方式、接口与配置参数。
4. **来源记录**：把引用到的官方页面链接记录到文章的 sources 字段。
5. **核实日期**：写入 updatedAt，作为该信息的时效锚点。

任何一步无法完成，内容就停留在草稿状态，不对外发布。

## 内容状态机

本站每篇内容处于以下四种状态之一：

| 状态 | 含义 | 对外表现 |
| --- | --- | --- |
| draft | 内部草稿，未核验 | 不构建、不出现在站点与 sitemap |
| published | 已核验，正式上线 | 正常展示，标注更新时间 |
| outdated | 信息疑似过期 | 页面显示更新提示，等待复查 |
| inactive | 停止维护 | 移入历史记录，不参与推荐 |

## 更新频率

价格、地区覆盖、接口参数等易变信息以服务商官方页面为准。本站按核验队列定期复查已上线内容，复查后更新 updatedAt；发现官方信息已变化但尚未复查完成的，先标注 outdated。

## 官方声明、本站核验与编辑推荐的区别

- **官方声明**：服务商自己发布的信息，包括官网文案、定价页和文档。本站引用时会注明来源。
- **本站核验**：我们按上面的流程对官方声明做可访问性与一致性核对，并记录核实日期。核验只说明"官方确实这样写"，不代表独立实测。
- **编辑推荐**：核验通过，且能写明明确适用场景与限制的服务商，才会被标注为推荐。未完成核验的服务商一律不显示为推荐。
