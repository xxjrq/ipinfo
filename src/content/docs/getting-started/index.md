如果你正在为多账号运营、数据采集或跨区域访问寻找代理 IP，又不确定该买哪家的哪种产品，这份指南帮你快速建立选型思路。

## 什么是代理 IP

代理 IP 是位于你和目标网站之间的中转服务器地址。请求先经过代理转发，目标网站看到的是代理的 IP，而不是你的真实 IP。按来源可分为住宅、数据中心、移动等类型，识别难度与成本各不相同。概念细节见[IP 基础](../basics/)，类型差异见[代理类型](../proxy-types/)。

## 本站能帮你做什么

本站是一个代理 IP 资源导航与选型平台，不是服务商，也不直接出售代理。你可以在这里：

- **浏览**：查看按核验标准收录的服务商与代理产品。
- **筛选**：按代理类型、地区覆盖、认证方式等条件缩小范围。
- **比较**：对照不同服务商的产品线、计费模式与适用场景。
- **避坑**：了解各类代理的常见误区与核验要点。

## 如何使用本站

建议按四步走：

1. **明确需求**：你做什么业务？目标平台是谁？预算多少？场景问题可参考[使用场景](../use-cases/)。
2. **确定类型**：根据业务在住宅、静态住宅、移动、数据中心代理中选一类，见[代理类型](../proxy-types/)。
3. **筛选服务商**：到[IP 服务商](../providers/)栏目按覆盖、认证、计费、稳定性、支持五个维度比较。
4. **核验再购买**：下单前打开服务商官方页面核对价格与套餐，并留意本站标注的核实日期。

## 三种信息的区别

阅读本站内容时，请分清三种信息来源：

- **官方声明**：服务商官网自己写的内容。它是价格和功能的最终依据，但天然带有营销立场。
- **本站核验**：我们对官方页面的可访问性与一致性做的核对，并记录核实日期。核验说明"官方确实这样写"，不代表独立实测。
- **编辑推荐**：核验通过、且能写明适用场景与限制的服务商才会被标注为推荐。未核验的一律不推荐。

详细规则见[服务商如何入选与核验](../about/how-we-review/)，利益关系见[推广关系披露](../about/affiliate-disclosure/)。
