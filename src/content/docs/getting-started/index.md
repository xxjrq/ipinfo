EasyBR 指纹浏览器为每个账号创建独立的浏览器环境，通过代理 IP 让每个环境的网络出口互相隔离。本文给出完整的上手路径。

## 第一步：下载并安装 EasyBR

前往 [EasyBR 官网](https://www.ebrower.com/) 下载对应系统版本（Windows / macOS）。安装后打开，使用账号登录即可进入环境管理界面。

## 第二步：创建浏览器环境

在环境列表中新建环境。每个环境拥有独立的指纹参数与存储空间，相当于一台独立的虚拟浏览器。免费版可创建 5 个永久免费环境。

## 第三步：添加代理 IP

进入环境的代理设置，选择代理类型（HTTP / HTTPS / SOCKS5），填入服务商提供的主机地址、端口、用户名与密码，保存并开启代理。

## 第四步：检测连通性

开启环境后访问 IP 检测站点，确认出口 IP、时区与语言和代理设置一致。若出现泄漏或失配，参考[排查工具](../troubleshooting/)中的方法定位问题。
