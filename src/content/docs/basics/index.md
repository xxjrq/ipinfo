本栏目介绍使用代理 IP 前必须理解的基础概念。

## 什么是代理 IP

代理 IP 是位于你和目标网站之间的中间服务器地址。请求先经过代理转发，目标网站看到的是代理的 IP 而非你的真实 IP。代理 IP 有住宅、数据中心、移动等多种类型，各有不同的识别难度与成本，详见[代理类型](../proxy-types/)。

## 三种主流代理协议

- **HTTP 代理**：处理网页请求，只支持 HTTP 明文流量，配置最简单。
- **HTTPS 代理**：在 HTTP 基础上支持加密流量（CONNECT 隧道），适合绝大多数网页场景。
- **SOCKS5 代理**：工作在更底层，支持任意 TCP/UDP 流量，可覆盖邮件、游戏等非网页应用。

## 代理与指纹浏览器

单靠代理只能隐藏 IP，浏览器仍会暴露时区、语言、字体、WebGL 等指纹信息。指纹浏览器为每个环境隔离这些参数，代理再隔离网络出口，两者配合才是完整的防关联方案。在 EasyBR 中添加代理的步骤见[EasyBR 配置](../easybr/)。
