本栏目集中说明 EasyBR 指纹浏览器中的代理配置方式。所有操作步骤均以当前产品界面为准。

## 支持的代理协议

EasyBR 环境代理支持 HTTP、HTTPS 与 SOCKS5 三种协议，覆盖主流服务商的接入方式。选择协议时需与服务商提供的参数类型一致。

## 配置流程概览

1. 打开环境列表，进入目标环境的代理设置。
2. 选择代理类型，填写主机、端口、账号与密码。
3. 保存后开启代理，启动环境验证出口 IP。
4. 检测通过后该环境即固定使用该代理。

## 批量导入

同一服务商的多组代理参数可通过批量导入一次性录入，按固定格式逐行填写主机与账号信息，适合需要为大量环境批量分配代理的场景。

## 环境级隔离

每个环境独立绑定代理，环境之间的指纹参数与网络出口互不干扰，这是多账号防关联的核心机制。
