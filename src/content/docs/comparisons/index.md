配置代理前先做两个关键决策，本栏目围绕这两个决策提供对比视角。

## 选哪种代理类型

住宅 IP 隐蔽性最好但成本高，数据中心 IP 速度快成本低但易识别，移动 IP 具备真实运营商属性。不同平台的检测强度不同，具体取舍见[代理类型](../proxy-types/)栏目。

## 代理与指纹浏览器怎么配合

代理只解决网络出口问题，无法隔离时区、字体、WebGL 等浏览器指纹。指纹浏览器负责环境级指纹隔离，代理负责网络出口隔离，二者配合才是完整的防关联方案。机制说明见[IP 基础](../basics/)。

## 对比的方法论

任何对比都建议回到三个问题：目标平台的风控强度如何？预算上限是多少？对速度与稳定性的要求有多高？带着答案看对比结论，比直接套用结论更可靠。
