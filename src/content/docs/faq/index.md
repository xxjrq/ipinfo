这里汇总代理 IP 与 EasyBR 指纹浏览器配合使用的高频问题。条目会随产品迭代持续补充。

## 代理连接失败怎么办

先确认代理类型与参数填写一致，再检查账号密码是否有效、端口是否被防火墙拦截。若仍失败，查看[排查工具](../troubleshooting/)中的错误定位方法。

## 出口 IP 与代理设置不一致

说明代理未生效，常见原因是环境未开启代理或浏览器走了直连。开启代理后需重新启动环境验证。

## 如何检测是否泄漏

访问 IP 检测站点，对比出口 IP、时区与语言。若与代理参数一致则正常；出现真实 IP 说明存在泄漏，需检查 WebRTC 与 DNS 配置。

## EasyBR 免费版有多少环境

免费版可创建 5 个永久免费环境，支持 HTTP、HTTPS 与 SOCKS5 代理，Windows 与 macOS 均可使用。

## 一个代理可以给多个环境用吗

技术上可以，但多个环境共用同一代理会导致出口 IP 相同，失去防关联意义，建议每个环境绑定独立代理。
