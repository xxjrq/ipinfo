不同类型的代理 IP 来自不同的网络来源，直接决定识别难度、速度与价格。本栏目逐步拆解每种类型的特点与适用场景。

## 住宅代理

住宅代理使用真实家庭宽带用户的 IP，普通网站难以区分它与真实用户，识别风险最低。价格相对较高，适合跨境电商、社媒多账号等对稳定性要求高的防关联场景。

## 数据中心代理

数据中心代理来自云服务商的机房 IP，速度快、价格低，但容易被风控系统识别为机房流量。适合数据采集、批量注册等对隐蔽性要求不极端的场景。

## 移动代理

移动代理使用 4G/5G 运营商的移动网络 IP，由运营商动态分配，更换频繁。适合需要真实移动网络属性的场景，成本通常最高。

## ISP 代理

ISP 代理是数据中心代持的静态住宅 IP，兼顾住宅 IP 的低识别度与数据中心的速度。价格介于住宅与数据中心之间。

## 如何选择

选型没有唯一答案，需要结合预算、目标平台的风控强度、地区覆盖需求综合判断。想了解不同类型与指纹浏览器的配合方式，见[IP 基础](../basics/)与[EasyBR 配置](../easybr/)。
