## 适合哪些用户

- 适合需要固定私有入口（独立 IP）的账号注册与登录场景
- 需要美国/欧洲机房 IP 的跨境业务与广告验证
- 按 IP 计费适合 IP 数量需求明确、追求稳定预算的团队

## 主要特点

- 按 IP 计费（非按流量），提供美国/欧洲机房私有数据中心 IP

## 需要注意的限制

- 无试用，需先付费后使用
- 仅提供数据中心 IP，无住宅/移动代理产品，且认证方式仅账号密码
