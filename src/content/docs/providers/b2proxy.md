## 适合哪些用户

- 多账号社媒运营需要住宅 IP 且要求会话保持稳定的团队
- 需要住宅与数据中心混合方案的电商运营与广告投放验证场景

## 主要特点

- 支持会话保持（sticky）与 API 提取，适配多账号运营场景
- 覆盖全球 190+ 国家，住宅与数据中心产品可选

## 需要注意的限制

- 认证仅支持账号密码与 API 接入，未提供 IP 白名单方式
- 无免费试用，初次评估需付费
