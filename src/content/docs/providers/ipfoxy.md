IPFoxy 是面向全球用户的住宅代理服务商，并有静态住宅产品线，覆盖 覆盖全球及亚洲多地区，具体以官网当前列表为准。资料基于官方公开页面整理，未做主观评分。

- traffic
- ip

## 适合哪些用户

- 适合出海电商与广告投放团队，用中文服务按城市定向海外住宅 IP
- 需要静态住宅 IP 维持固定登录环境的账号运营业务
- IP 计费模式适合需要长期独占固定 IP 的企业客户

## 主要特点

- 支持按流量与按 IP 两种计费方式，并提供中英双语服务

## 需要注意的限制

- 住宅代理按流量计费，长时间大流量场景成本较高
- 静态住宅可用地区需以官方当前列表为准
