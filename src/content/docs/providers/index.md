市场上代理服务商众多，价格、质量与可靠性差异很大。本栏目帮助你建立选择标准，并持续发布经过核实的服务商导入教程。

## 五个评估维度

- **地区覆盖**：是否覆盖目标市场所在国家与城市，IP 池规模大小。
- **认证方式**：用户名密码、IP 白名单或 API 接入，是否方便在 EasyBR 中直接配置。
- **计费模式**：按流量、按 IP 数或按时长计费，是否存在最低消费。
- **连接稳定性**：可用率、速度与掉线频率，可通过试用期实际检测。
- **售后支持**：文档完整度、工单响应速度，是否提供中文支持。

## 本站教程的核实标准

每篇服务商教程发布前，我们会逐项核对官方页面：套餐与价格、地区覆盖、认证流程、后台操作路径，并记录来源链接与核实日期。未通过核实的服务商不会上线教程，因此本栏目会随核实进度逐步扩充。
