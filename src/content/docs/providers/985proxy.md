## 适合哪些用户

- 需要长时间复用同一固定 IP 的场景（账号养号、电商多账号运营、社媒账号管理），静态住宅池保证 IP 稳定不轻易失效
- 对 IP 稳定性与速度要求高的业务，如需要固定地理位置入口的数据采集与店铺运营
- 预算按 IP 或按量灵活的团队（定价模型覆盖 ip 与 traffic），按需控制成本

## 主要特点

- 2000 万+ 原生静态住宅 IP 池，官网强调高稳定性与高速度
- 支持国家/城市级粒度选择，可按需锁定固定地理位置
